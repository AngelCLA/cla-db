// Características

Dentro del motor.

Datos locales

Lee y guarda datos en el dispositivo, incluso sin conexión. La app sigue funcionando completa en el bar, en el campo o en un vuelo.

Consultas reactivas

Suscríbete con .find().$ y actualiza la interfaz en tiempo real: cada inserción, actualización o sincronización re-emite el resultado.

Más colecciones

Organiza clientes, ventas y abonos en colecciones separadas. CLA DB elimina el límite artificial de 13 colecciones del core abierto.

Replicación bidireccional

Sincroniza con tu backend existente mediante la Sync Engine: checkpoints, reintentos y resolución de conflictos incluidos.

Persistencia verificada

La suite de verificación comprueba CRUD, reinicios, migraciones de esquema y persistencia tras cerrar la app, con 100 colecciones.

API de RxDB intacta

Fork mínimo con base RxDB 17.6.0: tu código existente se mueve sin cambios. ESM, CJS y tipos de TypeScript listos para usar.

// Arquitectura

Fork mínimo, marcado.

CLA DB no reescribe RxDB. Es un fork Apache 2.0 anclado en RxDB 17.6.0 (commit 9d5849cf) que mantiene la API pública, el formato en disco y la Sync Engine tal como están.

Cada modificación del fork está aislada y marcada con comentarios // CLA-DB:, así que las futuras actualizaciones de upstream se aplican con fricción mínima. Las extensiones nuevas llegan como paquetes independientes, nunca dentro del core.

Sin plugins propietarios, sin flags de licencia falsificados y sin history rewrites. Solo los cambios que el fork necesita, documentados en UPSTREAM.md y CLA_CHANGELOG.md.

// Documentación

Empezá en cinco minutos.

Instalá el paquete, creá la base con tu storage preferido y subscribí tu primera consulta reactiva. La documentación hereda el recorrido completo de RxDB: quickstart, storages, replicación y migraciones.

app.ts
// Consulta reactiva: se re-emite con cada cambio.
import { createRxDatabase } from '@clatech/db';

const db = await createRxDatabase({
  name: 'clientes',
  storage: getRxStorageDexie()
});
await db.addCollections({ clientes: { schema: clienteSchema } });
await db.clientes.insert({ id: 'c-001', nombre: 'Ana', plan: 'abono' });

db.clientes.find({ selector: { plan: 'abono' } })
  .$.subscribe(docs => render(docs));

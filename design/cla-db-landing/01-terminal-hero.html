A fast, local-first, reactive database for JavaScript.
Open source, uncapped.

CLA DB (@clatech/db) is a minimal Apache 2.0 fork of RxDB, anchored on the RxDB 17.6.0 codebase. Same reactive API, same on-disk format, and no artificial collection limit.

app.ts
// One reactive query. It re-emits on every change, in every tab.
import { createRxDatabase } from '@clatech/db';

const db = await createRxDatabase({
  name: 'receipts',
  storage: getRxStorageDexie()  // or memory, localstorage, sqlite
});
await db.addCollections({ receipts: { schema: receiptSchema } });
await db.receipts.insert({ id: 'r-001', total: 1990, device: 'pos-07' });

db.receipts.find({ selector: { total: { $gt: 0 } } })
  .$.subscribe(docs => render(docs));
